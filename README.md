SGPET · Sistema de Gestión de Préstamos de Equipamiento Tecnológico

Proyecto de la asignatura Ingeniería de Software — Ce.R.P. del Suroeste, 2026. Autoras: Castro · Sáenz · Sánchez

Descripción

El Laboratorio de Informática de la institución gestiona el préstamo de Ceibalitas e insumos del espacio Ceilab (placas Micro:bit, kits de robótica, impresoras 3D, sensores fisicoquímicos) mediante planillas en papel o electrónicas. El SGPET propone digitalizar ese proceso: inventario, registro de usuarios, préstamos, reservas, devoluciones e historial de uso, para administradores, docentes y estudiantes.

Este repositorio contiene el sitio web (index.html) donde se presenta el proyecto completo:

El proyecto: contexto y problema a resolver.
Técnicas de elicitación: entrevista estructurada, cuestionario y observación ("mosca en la pared") aplicadas para relevar requerimientos.

FODA: fortalezas, oportunidades, debilidades y amenazas del proyecto.
Factibilidad: análisis de factibilidad operativa, técnica, económica y legal, con evidencias, riesgos y conclusión de viabilidad.

Anexos: pautas de entrevista, cuestionario y registros de observación.
